# Stockpile

A Minecraft 1.21.1 NeoForge mod inspired by Silent Gear. Adds weapons and armor for all tiers using only base game materials. Each equipment type (warrior, mage, archer) is crafted from 3 components, supporting a variety of playstyles.

## Features
- Weapons and armor for all vanilla material tiers
- Three playstyles: Warrior, Mage, Archer
- Each equipment type uses exactly 3 components
- Only base game materials (no modded materials)

## Folder Structure
- `assets/stockpile/` — Textures, language files, etc.
- `data/stockpile/recipes/` — Crafting recipes
- `META-INF/` — Mod metadata and mixins
- `net/stockpile/` — Java source code
