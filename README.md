# Stockpile

A Minecraft 1.21.1 NeoForge mod inspired by Silent Gear. Adds a complete tier progression system with 72 tools across 6 tiers using only vanilla materials.

## 🚀 Quick Start

**For Players:**
1. Download the latest release
2. Install NeoForge 21.1.57 for Minecraft 1.21.1
3. Place the mod JAR in your `mods/` folder
4. Launch Minecraft and enjoy!

**For Developers:**
1. Clone the repository
2. Run `./gradlew build`
3. See the [📖 Wiki](../../wiki) for detailed setup instructions

## ✨ Features

- **6-Tier Progression** - From toy swords to dragonsteel weapons
- **72 Total Tools** - 9 tools per tier across 8 material sets
- **Vanilla Materials Only** - No modded dependencies
- **Multiple Tool Types** - Swords, spears, axes, pickaxes, shovels, hoes, shears, fishing rods, paxels
- **87 Achievements** - Complete advancement system
- **Loot Integration** - Find tools in vanilla structures

## 🎯 Tier Overview

| Tier | Materials | Equivalent | Special Features |
|------|-----------|------------|------------------|
| **0** | Toy (Wool) | Fun | Dyeable, roleplay item |
| **1** | Bone | Wood+ | High damage, cheap repairs |
| **2** | Hardened Clay, Crystal Glass | Stone | Balanced vs. Fast but fragile |
| **3** | Copper, Obsidian Alloy | Iron | Balanced vs. High durability |
| **4** | Adamantine | Diamond+ | Diamond + Iron fusion |
| **5** | Voidsteel, Starlight Steel | Netherite+ | Balanced vs. Ultra-fast |
| **6** | Dragonsteel | Ultimate | Dragon's power |
